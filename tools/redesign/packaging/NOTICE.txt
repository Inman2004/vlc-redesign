VLC Redesign — modified version of VLC media player 3.0.24
==========================================================

This is a MODIFIED, UNOFFICIAL build of VLC media player 3.0.24. It is not
made, endorsed or supported by VideoLAN. The official player is at
https://www.videolan.org/vlc/

Changes
-------
Modified in 2026 by Immanuvel B (https://github.com/Inman2004):

- modules/gui/qt/: a redesigned Qt interface (new and changed files
  throughout the module);
- configure.ac: the Qt Network module made optional;
- extras/package/win32/: Windows packaging without browser plugins, and
  the NSIS files missing from the 3.0.24 source release;
- tools/redesign/: build and packaging scripts.

The full record of every change, with dates, is the git history of the
source repository. The original VLC copyright notices are unchanged.
